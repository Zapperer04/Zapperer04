## 🏆 Headline Work

### 🌾 Bhoomi-Mitra — Farmer–Contractor Marketplace (Patent Published)
A real-world **agri marketplace** that connects farmers with contractors for crop deals and services.

- 🔐 Role-based auth (Farmer / Contractor) with JWT  
- 🌾 Crop listings, offers, negotiations, and waitlists  
- 📨 In-app messaging and notifications  
- 🌍 Multi-language UX and MSP / weather integrations  

**Stack:** Python, Flask, SQLAlchemy, JWT, PostgreSQL, HTML/CSS/JS  

> 🏛️ Patent published under Government of India.

---

### ⚡ ScaleFlow — Distributed Task Engine
A **distributed task orchestration system** built for horizontal scale.

- 🧵 Queue-based producer–consumer architecture  
- 📬 Redis FIFO queue for jobs  
- 🗃 PostgreSQL for durable task state  
- 📊 React dashboard for real-time monitoring  
- 🐳 Fully containerized with Docker  

**Stack:** Python, Flask, React, Redis, PostgreSQL, Docker  

---

### 💬 SocketChat Pro — Real-Time Multi-Client Chat
A **multi-threaded TCP chat system** with a modern web UI.

- 👥 Group & private messaging  
- 📁 File transfer (up to 5 MB)  
- 👀 Active users list  
- 🧾 Rich server logging  
- 🌐 Web UI served via Flask  

**Stack:** Python (`socket`, `threading`), Flask, HTML, CSS, JavaScript
